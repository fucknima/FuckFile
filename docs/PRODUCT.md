# Product Specification

## 产品定位

一个面向高级用户的 iOS / iPadOS 文件管理器。

目标：

- 本地文件管理
- 快速文件浏览
- 强大的文件操作
- 文件预览
- 压缩解压
- 网络文件访问
- 搜索
- 收藏
- 批量管理
- 高性能大目录浏览

后期可逐步增加高级能力。

## 1. 文件浏览

### 基础浏览

- 文件夹导航
- 返回上级
- 路径导航（面包屑条：单行横向滚动、只显示祖先层级（当前目录不重复，
   由导航标题承担）、直接父级加粗、尾部箭头指示、上级目录可点；
   根目录收起，不显示完整绝对路径）
- 文件列表
- 网格模式（自适应列数）
- 列表模式
- 显示方式：浏览器内快速切换；设置页「默认视图」决定新打开目录的初始模式
- 文件夹优先显示选项
- 显示隐藏文件
- 文件数量显示

### 文件信息

列表行只显示名称、类型/大小与相对时间。独立文件信息页显示：

- 名称
- 类型
- 完整路径（可复制）
- 链接目标（符号链接，可复制）
- MIME Type
- 大小
- 修改时间
- 创建时间
- 项目数量（文件夹递归统计）
- 扩展名
- 权限 / 属主 / 扩展属性（进入页面后后台加载）

### 排序

支持：

- 名称
- 文件大小
- 修改时间
- 创建时间
- 文件类型
- 升序
- 降序

### 筛选

按：

- 文件夹
- 图片
- 视频
- 音频
- 文档
- 压缩包
- 代码
- 其他

## 2. 基础文件操作

支持：

- 新建文件夹
- 新建文本文件
- 重命名

- 剪切

- 移动
- 删除
- 批量删除
- 批量移动
- 批量复制

- Duplicate / 创建副本

### 外部文件进入

- 「打开方式」/分享：其他应用可将文件发给 FuckFile，
  自动拷贝到 Device Storage/Imported/ 并提供「前往查看」
- 浏览器 `＋ → 导入文件…`：系统文件选择器导入到当前目录，
  重名自动加序号，不静默覆盖
- 压缩目标名已存在时提供「替换 / 保留两者 / 取消」，不静默覆盖

## 3. 多选系统

支持：

- 进入选择模式

- 全选

## 8. 文件预览

### 查看器体系

所有预览统一走：文件 → Preview Router → 文件关联 → Viewer Registry → 对应 Viewer。

内置查看器：

- 图片浏览器（png/jpg/jpeg/gif/heic/webp/bmp/tif/tiff/ico/car）
- 快速查看（系统 Quick Look，无专用查看器文件的兜底）
- Web Viewer（html/htm 本地页面；url/webloc 网页快捷方式）
- 属性表编辑器（plist，XML/二进制）
- 代码/文本编辑器（Runestone + Tree-sitter：txt/log/md/json/xml/源码等；
  语法高亮、行号、查找替换、跳转行、编码/换行符保持；脚本仅按文本打开，不执行）
- SQLite3 编辑器（sqlite/sqlite3/sqlitedb/db：库信息、表、视图、索引、
  schema、分页浏览、SQL 查询）
- IPA 安装器（解析应用信息与图标；安装能力取决于运行环境并如实反馈）
- ZIP 浏览器（zip/ipa 包内目录浏览、单文件预览、选中提取、全部解压；
  tar/gz/7z/rar/xz/bz2 当前构建明确提示暂不支持）
- 十六进制编辑器（分页 OFFSET/HEX/ASCII，支持字节修改、保存、取消）
- 系统诊断查看器（.ips：JSON Header 元数据、zlib/raw-DEFLATE 解压、
  RHWN 安全识别与导出，复用文本/Hex 查看器）
- 媒体播放器（mp3/wav/m4a/aac/aif/aiff/aifc/caf/m4b/m4p/m4r/flac/
  mov/mp4/m4v/3gp/avi/mkv）
- PDF 阅读器

明确排除：终端、脚本执行、DEB 专用功能。

## 19. 设置

### 文件查看

- 支持的文件查看器（全部 Viewer 的名称、图标、能力说明；提供「恢复默认关联」）
- 文件关联（扩展名 → 查看器映射列表，点入选择查看器立即生效；
  支持新增自定义扩展名、删除覆盖/自定义项、恢复默认）

关联规则：

- 内置默认关联随 App 内置；用户修改只保存覆盖项
- 升级新增默认格式不覆盖用户已有选择
- 最长后缀优先匹配（backup.tar.gz 先试 .tar.gz 再试 .gz）
- 大小写不敏感、前导点规范化

### 显示

- 默认视图（列表 / 网格；仅影响新打开的目录）
- 图标大小
- 是否显示扩展名
- 是否显示隐藏文件
- 文件夹优先
- 日期格式
- 文件大小格式

### 文件操作

- 删除确认（当前恒为确认弹窗，安全默认）
- 覆盖确认（冲突时替换/跳过/保留两者/应用于后续）
- 默认冲突策略（显示扩展名与默认冲突策略选项待 backend 就绪后进入设置页）

### 缓存

- 缩略图缓存
- 清理缓存

### 外观

- 跟随系统
- Light
- Dark
