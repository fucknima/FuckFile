# Roadmap

## V0.1 - 文件管理核心

目标：

成为一个真正能使用的本地文件管理器。

包括：

- 文件列表
- 文件夹导航
- 列表模式
- 网格模式
- 排序
- 文件类型
- 文件图标
- 新建文件夹
- 重命名
- 复制
- 移动
- 删除
- 多选
- 批量操作
- 分享
- 文件属性
- 基础错误处理

完成后才进入 V0.2。
